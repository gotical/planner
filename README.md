# Планировщик — РыбинскLAB

Полностью офлайн-менеджер задач и календарь для Android. Без рекламы, без
подписок, без учётных записей и без передачи данных куда-либо. Все данные
хранятся локально на устройстве (SQLite).

Разработан с нуля командой **РыбинскLAB** · [rybinsklab.ru](https://rybinsklab.ru)

> ⚖️ **Независимый проект.** Приложение разработано самостоятельно и не
> аффилировано ни с какими сторонними продуктами. См. [NOTICE](NOTICE).

## Возможности

- **Задачи**: подзадачи, приоритеты, повторение (ежедневно/еженедельно/…),
  теги с цветами, закрепление, заметки.
- **Напоминания**: до 5 на задачу, отложить (snooze) прямо из уведомления.
- **Календарь**: режимы Месяц / Неделя / День.
- **Умный ввод**: «завтра в 18:00», «через 3 дня», «в пятницу».
- **Списки** с цветами, список по умолчанию.
- **Привычки** со счётчиком серии (streak).
- **Фокус-таймер** (Помодоро) с журналом и статистикой.
- **Статистика**: график выполнения за 7 дней, время в фокусе.
- **Организация**: «Won't Do», корзина (мягкое удаление, автоочистка 30 дней),
  отмена удаления, шаблоны задач, поиск.
- **Резервная копия**: экспорт/импорт всех данных в JSON.
- **Ежедневный обзор**: утреннее уведомление с планом на день.
- **Оформление**: светлая/тёмная тема, 8 акцентных цветов, 12/24-часовой формат.

## Сборка

Приложение написано без внешних зависимостей (чистый Android SDK, Java).
Для сборки нужны только инструменты Android SDK: `aapt2`, `javac`, `d8`,
`apksigner`.

```bash
# настройте переменные в build.sh (пути к SDK) и запустите:
./build.sh
```

Результат — подписанный APK в `build/planner.apk`.

## Структура

```
Planner/
├── AndroidManifest.xml
├── res/                  # ресурсы (строки, тема, иконки)
├── java/ru/rybinsklab/planner/
│   ├── MainActivity.java # интерфейс и навигация
│   ├── Store.java        # SQLite: задачи, списки, теги, привычки, фокус
│   ├── Ui.java           # палитра и UI-хелперы
│   ├── Reminders.java    # планирование напоминаний (AlarmManager)
│   ├── ReminderReceiver.java
│   ├── DailyReceiver.java
│   └── BootReceiver.java
└── build.sh              # скрипт сборки APK
```
